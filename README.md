# listicus-data

Public data of [Listicus](https://40k.mazakiel.com), a Warhammer 40,000 list builder. Generated by `npm run export-data`
in the app repository: do not edit by hand.

| Path | Content |
|---|---|
| `factions.json` | Factions (id, name, number of datasheets, source update date). |
| `catalogs/<faction>.json` | Datasheets (profiles, weapons, keywords, point costs), wargear options, names and costs of abilities, detachments, enhancements and stratagems. **Rule texts are not included** (empty fields, `locked: true`), except Core rules. |
| `targets.json` | Target profiles for the damage simulation. |
| `rules/<faction>.json` | Simulation rules encoded by hand (what each rule changes in an attack roll), with short notes in the author's own words. `hash` fingerprints the source text used when encoding; it does not contain it. |
| `assets/` | Faction symbols (SVG) and icons. |
| `manifest.json` | Format version and fingerprint (SHA-1, base64url, 16 characters) of each file. |

The app loads these files through the jsDelivr CDN at a pinned tag
(`https://cdn.jsdelivr.net/gh/Mazakiel/listicus-data@<tag>/<path>`), checks each file against the fingerprint announced by
its server, and falls back to its server otherwise.
